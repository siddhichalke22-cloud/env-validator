# env-validator

A lightweight environment variable validator for Node.js applications.

## Requirements

- Node.js 18 or later

## Development

Install the development dependencies and run the test suite:

```sh
npm install
npm test
```

## Status

The package API is not implemented yet. Usage instructions will be added when
the public API is available.
